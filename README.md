# CompassOverlay

Shows cardinal direction and coordinates at the top of the screen whenever a compass is in the inventory.

## Requirements

Minecraft 1.21.1, NeoForge 21.1.219 or newer, and Cloth Config API 15.0.140 or newer.

## Installation side

Client-side only.

## Configuration

Configuration is available through the Cloth Config screen and is persisted in the instance's config directory.

## Development

Source code for NeoForge 1.21.1 is maintained on the 
eoforge/1.21.1 branch. This documentation-only branch intentionally contains no mod source code.
